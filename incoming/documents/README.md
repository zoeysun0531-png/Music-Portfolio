# incoming/documents

Drop planning documents, notes and working files here. No need to rename or tidy — I will read, select and organise them.

Suggested folders:

- `kc-voice/` — production book, run sheets, cue sheets, stage plans, budgets, promo copy, handover notes
- `sad-music-healing/` — project brief, recruitment and team documents, TEDx booth plan, social media plan
- `charity-single/` — lyrics, chord charts, recording notes, release copy
- `student-council/` — event plans, committee documents, handover material
- `re-cloth/` — pitch deck, research, business model
- `jazz/` — artist briefings, schedules, content drafts
- `other/` — anything that does not fit above

Accepted formats: PDF, DOCX, PPTX, KEY, XLSX, Pages, Numbers, images, ZIP.

A few practical notes:

- Files stay on this Mac; I only use them to choose what belongs on the site.
- If a document contains phone numbers, emails, student names, private venue contacts or budget details, either redact it first or tell me it is confidential. I will not publish confidential material.
- I will pick only what strengthens the portfolio (process, structure, outcomes) rather than publishing entire internal documents.
- If a file is very large, a PDF export is usually enough.
