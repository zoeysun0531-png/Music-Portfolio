Overwrite the current placeholder images — no code changes needed.

- `.jpeg`, `.png` and `.webp` also work.
- A long edge of 1600–2400px is ideal; portrait and landscape both crop well.
- Captions, order and alt text live in `photos` in `../js/config.js`.
- Band names, roles and copy live in `bands` in `../js/config.js`; logos go in `../logo/`.
- `studio.jpg` is the portrait studio image in the Bands section; its caption is in `index.html`.
- `case-*.jpg` are selected artifacts for the Case files section: pitch slides, plan covers, the SAD concept sketch and the student council portrait crop. Case-file narratives and captions live in `caseFiles` in `../js/config.js`.
- iPhone HEIC files must be exported to JPG first.
