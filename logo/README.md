# logo / band logos

Put the two band logos here:

```
logo/infinity.png
logo/70soul.png
```

- Transparent PNG or SVG works best; 400–800px wide is enough.
- A dark or coloured logo reads best on the cream paper background. White-only logos may disappear.
- If the filenames are different, edit `bands[].logo` in `../js/config.js`.
- When a logo is missing, the site uses the band name as a typographic wordmark — the card still looks intentional. Both band logos are now connected; 70%Soul uses a transparent PNG prepared from the uploaded artwork.
