# certificate / scans

Put certificate or programme scans here, for example:

```
ap-scholar-honor.png
sic-bronze.png
topik.png
```

The AP, SIC and TOPIK scans are already connected to the three Achievement cards. Add future scans here and reference them in `recognitions` in `../js/config.js`:

```js
file: "certificate/certificate-01.jpg"
```

Each card shows the full scan and opens the original PNG or PDF in a new tab. JPG, PNG and PDF are fine; keep each under 1MB.
