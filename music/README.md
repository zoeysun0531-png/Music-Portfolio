# music / recordings

Two tracks are already connected: `01.m4a` (Goodnight) and `02.mp3` (Kismet). Add the remaining three:

```
01.mp3
02.mp3
03.mp3
04.mp3
05.mp3
```

Refresh the site. Each row picks up its duration automatically.

- `1.mp3`, `track1.mp3` and `track-01.mp3` are also detected.
- For completely different names, edit `file` in `../js/config.js`.
- MP3, M4A and WAV are supported; MP3 at 128–320 kbps is recommended.
